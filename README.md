# Calculadora de Licença — INTELIAR™

Aplicação web que calcula o valor da licença de software Inteliar e gera o escopo do projeto para o desenvolvedor. Substitui a planilha `Calculo_Inteliar_v2.xlsm`.

**Acesse:** https://isac-de-sa.github.io/calculadora-inteliar/

## Como usar
1. Escolha a plataforma: **Padrão** ou **LOGO!** (versão simplificada — alguns itens ficam indisponíveis).
2. Marque as funcionalidades de cada módulo e os serviços.
3. Confira o valor no resumo (com desconto, se houver).
4. Clique em **Gerar escopo para o desenvolvedor** para copiar ou baixar (.md / .csv).
5. **Salvar proposta** guarda o cálculo no histórico.

## Proposta ao cliente
Na aba **Proposta ao cliente** (ou no botão "Gerar proposta para o cliente"):
1. Preencha uma vez os **dados da sua empresa** (nome, CNPJ, endereço, contato e logo) e clique em **Salvar dados da empresa**.
2. Ajuste as **condições desta proposta**: validade, pagamento, prazo e observações.
3. Escolha se quer **detalhar os valores por item** e **listar as funcionalidades padrão**.
4. Clique em **Salvar em PDF / Imprimir** e escolha "Salvar como PDF" — ou baixe a proposta em .html.

## Onde ficam os dados
Preços e propostas salvas ficam no navegador de cada aparelho (não há servidor).
Use **Propostas salvas → Exportar backup** para guardar ou levar os dados para outro aparelho.

## No celular
Abra o endereço no navegador e use "Adicionar à tela de início".
